# NVIDIA driver 570.124.06 with P2P for 4090

This allows using P2P on 4090 GPUs with the 570.124.06 driver version.
See https://github.com/tinygrad/open-gpu-kernel-modules for more info.

Note 570.124.04 version is identical to 570.124.06

## How to Build

1) Install https://www.nvidia.com/en-us/drivers/details/241089/ 
2) Run `./install.sh`
3) Reboot
